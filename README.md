# ⚔️ Battle Game

A simple console-based battle game built with **Python** and **Object-Oriented Programming (OOP)**.

## 🎮 Features

* Character selection: Soldier, Sniper, Healer
* Weapon selection
* Mission selection
* Turn-based battles
* Random enemy selection
* Character and weapon leveling
* Special Healer ability

## 🧩 Main Classes

* `Game` — Controls the game and menus
* `Character` — Stores character information
* `Weapon` — Stores weapon information
* `Mission` — Manages missions
* `Battle` — Handles combat
* `Level` — Handles leveling up

## 🛠️ Technologies

* Python 3
* Object-Oriented Programming
* `random` module
